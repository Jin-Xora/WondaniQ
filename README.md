# Wondaniq website source

- `index.html`: homepage
- `explore.html`: topic categories and educational explainers (former blog archive)
- `topic-artificial-intelligence.html`: AI topic hub
- `ai-agents.html`: educational article
- `tools.html`: Resources directory
- `about.html`, `editorial.html`, `privacy.html`: publication information
- `blog.html`: redirect to Explore for old links

All pages load `assets/site.css`. The shared brand wash in `assets/brand-wash.png` is derived from the approved Wondaniq brand artwork and fades from the header into the page background.

Newsletter and live product/resource data integrations are not connected in this static source package.
